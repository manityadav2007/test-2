# FF ARENA - Free Fire Esports & Tournament Platform

A feature-rich, high-performance web application engineered for Free Fire competitive players, tournament hosts, and esports communities.

## 🎮 Features

- 🔥 **Competitive Tournament Hub**: Browse daily Free Fire custom matches across **Solo, Duo, Squad, and Clash Squad (4v4)** modes in Bermuda, Kalahari, Purgatory, and Alpine maps.
- 🔑 **Live Room Credential Center**: Real-time room ID and password countdown unlocker that automatically reveals credentials 10 minutes prior to match start.
- 💳 **Instant Wallet & Cashouts**: Deposit funds via UPI/Paytm, track per-kill and Booyah winnings, and request instant balance withdrawals.
- 🏆 **Live Leaderboards & Result Feed**: Weekly player rankings table tracking top earners/killers alongside verified match result reports.
- 🛡️ **Anti-Cheat & Fair Play Compliance**: Player UID validation system, strict emulator ban enforcement, and round-the-clock Discord support.
- 🎁 **Refer & Earn Program**: Shared referral code system rewarding players for inviting guild mates and team members.
- 🎨 **Esports Cyberpunk Aesthetics**: High-energy dark esports styling featuring glow accents, Rajdhani typography, and crisp gaming HUD elements.

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (React App Router)
- **Styling**: Tailwind CSS v3
- **Fonts**: Google Fonts (*Rajdhani* for headers, *Inter* for interface copy)
- **Icons**: FontAwesome 6.4

## 🚀 Getting Started

### Local Development

1. Install project dependencies:
```bash
npm install
```

2. Run the local development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to view the FF ARENA dashboard.

4. Build for production deployment:
```bash
npm run build
npm start
```

## 📜 Fair Play Guidelines

- Players must enter valid Free Fire Player UIDs and In-Game Names (IGNs).
- Scripts, macros, modded APKs, or unauthorized emulators are strictly prohibited.
